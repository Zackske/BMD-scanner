# BMD Scan 3.3.0

- Home: Scannen, Klantenportaal, Werkinstructies, Instellingen. Native translated text and vector tile controls follow the existing full-screen home geometry.
- Scannen: QR/count check, Box/pallet check, E-mail check, Document check. Only QR/count check is functional; the other modules and portal/instructions show Work in process.
- Guided QR/count: expected product count, Complete box / Inventory label, overview and four overlapping detail photos, compact camera toolbar, narrow centred zoom, floating counter/capture/gallery controls, animated lots sheet.
- Lot checklist: expand products, preserve original codes, edit lots with manual flag, explicitly review rows or a lot, exclude with undo. Expected count, at least four detail photos, known nonconflicting lots and explicit manual review gate saving.
- Save sheet: editable name, CSV/XLSX/DOCX/PDF, optional originals and annotated photos in a ZIP, native local picker or Android share chooser.
- Ten languages retained; new strings translated. Installed app name remains BMD Scan.

No barcode decoder or image-registration thresholds were relaxed. Tests use explicitly synthetic fixtures where indicated. Passing a synthetic 200-code test does not validate a physical 200-product carton. The supplied full-carton 95-product photographs did not yield valid codes in the previous build; recognition and association across new real close-up photographs remain experimental. A matched count is never automatic shipment approval.
