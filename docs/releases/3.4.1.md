# BMD Scan 3.4.1

Reference-style native bevelled pictograms replace the small outline icon wells on Home. Larger chrome QR, customer, work-instruction and gear icons have coloured orbital rings and subtle sparks. Settings gets matching detailed globe, palette and information icons. Tile labels stay real localized text.

Home and Settings now use the same safe-area viewport and shared HomeGeometry footer bounds, including width, height and position on all four themes. Settings content scrolls above the anchored footer on shorter screens.

Translumina retains its red background and Home colours. Its Settings tiles now retain blue for Language, purple for Themes and amber/orange for About, matching the Home palette. BMD, Dark and Light keep their theme treatments with cyan, purple and amber accents.

Native tests compare actual Home/Settings logo bounds per theme and sample Translumina tile colour identity, in addition to all existing tests. Camera, rotation, decoder, product identity, lot colours and export logic unchanged. Physical Samsung and real 95/200-product carton recognition still require practical validation; full-carton input photographs currently decode no valid codes. No automatic shipment approval.

Header now follows the approved BMD ScanTovenaar example: bold italic lettering, cyan/purple name on BMD/Dark, deep blue/purple on Light, ivory on Translumina, gold sparkle and subtle palette-coloured animated mist. Footer logos preserved.
