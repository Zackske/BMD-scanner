# BMD Scan 4.10.0

The Home tile opens final control directly. Scan type offers Final control and Pallet and boxes scan; the latter shows Work in progress. Separate picking, document and general QR scanner menu entries have been removed.

Final control keeps QR, Barcode and QR + Barcode filters, picklist review, quantities, lot colours, physical product instances and the marker/photo workflow. Tapping a detected code opens the shared silver result sheet, with copy/share and an explicit website action. Web previews load after a tap; ordinary web links do not increase the product count. Closing the sheet resumes the same camera view.

The changes retain ten languages, six themes, camera autofocus, pinch zoom and existing animations. Customer records remain private and are imported separately.

Validation: Android build, lint, unit tests, emulator suites for menus/customer import, scanner/settings and existing features, plus APK package/signature checks. Results are available in this build's GitHub Actions run. Real-device warehouse testing remains necessary before operational use.
