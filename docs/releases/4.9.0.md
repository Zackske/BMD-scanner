The general QR scanner now reads all supported QR, matrix and linear barcode formats together, with no format selector. The live camera and imported photos use the same decoder. Product-control workflows retain their existing picklist and carton checks.

Recognized links appear in a compact bottom sheet with silver details, an explicit browser action, a collapsible website preview, copy and share. Websites load only after a tap. The preview follows the HTTPS policy and supports retry and cleanup when closed. Opening, closing, torch and pinch-zoom animations are retained, with reduced-motion support. Labels follow the selected language and scanner surfaces follow all six themes.

The customer register remains private and is imported locally. This release includes the updated shipping-provider translations; no real customer records are included in the APK or public source.

Validation: Android build, lint, unit tests, signature checks, and emulator checks cover the scanner, link actions, preview lifecycle, menus, themes, languages, private import, and existing product-control flows. This is a phone-testing build; recognition and shipment checks still need verification against the actual products and working conditions.
