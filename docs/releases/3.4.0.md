# BMD Scan 3.4.0

Four persistent themes: BMD, ruby-red Translumina, neutral Dark and Light. Home retains blue/green/purple/orange tile identity; Scannen retains turquoise/orange/purple/blue. Translumina uses the same tile scheme over its red background, as Jack requested. Original alpha brand assets have no border or opaque plaque: ice-blue Blue Medical on BMD, white on Dark, original blue on Light, original red-arrow Translumina with readable grey lettering on red.

General settings now has Language, Themes, About. Scanner controls remain on the camera gear; CSV, Excel, Word and PDF remain in the save flow. Selecting a language previews the translated title, app name and Apply button immediately, before persistence. Ten languages and flags retained.

The guided live camera fills the available app area. Compact chrome, progress, gallery, counter and save controls float over the camera without any brand/logo area. The slim vertical rail uses hardware-clamped zoom with spring/ripple feedback. Successful CameraX zoom completion now updates its animated knob; no zoom labels are treated as additional counts. Menus are portrait-locked. Camera allows portrait and landscape; orientation changes retain the accepted box session and restart only temporary live observations.

Native palette, language-preview, orientation and zoom-feedback checks added to the existing scanner tests. Decoder, GS1 parsing, cross-photo matching and lot identity rules have not been loosened. Real 95/200-product performance remains unvalidated; supplied full-carton photographs previously yielded zero valid codes. This build is for practical phone testing and provides no automatic shipment approval.
