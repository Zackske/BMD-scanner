BMD Scan 4.13.0 adds eight coordinated themes: Ocean, Ember, Nature, Magic, Sunshine, Royal Gold, Roseheart and Midnight. Theme names are translated in all fifteen app languages. Light and Turquoise preferences migrate to Ocean.

The language picker keeps all fifteen flags and flag-colour backgrounds, replaces the centre ring with a 650 ms flip transition and enlarges the selected flag. The shared close cross is balanced, and the compact unframed back chevron follows the theme and reading direction across menus, customer portal, wizard and camera.

Theme previews update before Apply; closing restores the saved choice. The final-control camera retains its QR/barcode selector, pinch zoom, product counting, lot colours, picklist and marker workflow, and portrait/landscape operation. Menus remain portrait.

Customer records are not included in this public APK or repository. Import your separate private customer file locally. Keep that file private.

The release workflow runs build, lint, unit tests and Android emulator checks before publishing. This is an update for physical-phone testing; emulator checks do not replace real camera testing on products.
