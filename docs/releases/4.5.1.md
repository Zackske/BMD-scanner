# BMD Scan 4.5.1

- Added the approved thin dark contour to the localized home wordmark and scan-menu heading; theme gradients, smoke and native text remain intact.
- Removed the two decorative semicircles behind the scan-type question, preserving the gold sparkle.
- Replaced full-box and stack illustrations with transparent red/white medical-product artwork. The brown carton uses back and front banks perpendicular to the nine middle cartons; illustration density is decorative, not an item count.
- Fixed low-contrast full-box/stack labels on light-theme wizard tiles, verified by a native contrast regression assertion.
- Count step now shows the selected scan type's illustration.
- Shared implementation applies to all ten languages and six themes. Existing camera, tracking, marker alignment, capture sequence and animations are retained.

Validation: Android build, unit tests, lint, package/signature checks and two emulator test groups run before this release is published. Native wizard screenshots are retained with the run evidence. Physical Galaxy camera/torch behavior and accuracy on a real 95/200-product carton require Jack's device test; this UI update does not certify shipment accuracy.
