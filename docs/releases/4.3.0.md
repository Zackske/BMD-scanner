BMD Scan 4.3.0

- Pinch with two fingers to zoom in and out within the camera's actual hardware range. An animated zoom ratio appears during the gesture and fades away afterwards. The zoom bar has been removed.
- Scanner settings now open as the approved navy panel with resolution, sensitivity and vibration controls. The panel expands from the gear and closes back towards it using X, Done or Android Back.
- The last camera frame stays visible while settings are open. Closing resumes the camera in the same scan session, preserving the expected count, saved detections and preview view; resolution changes apply on resumption.
- Settings gear and three-dot control share a brushed silver finish; the Save ring uses the softer satin silver finish. Camera accents follow all six themes.
- Original full-box marker workflow, direct stack workflow, manual product review and ten languages remain available.

Validation: Gradle 8.9 and Java 17; unit tests, Android lint, APK package/signature checks and native Android emulator tests run before this release is published. Evidence is saved under docs/screenshots/attempt-<build>.

Device limits: the emulator camera has a fixed zoom range. The gesture recognizer and ratio limits are tested separately; physical Samsung zoom lenses and flash still need phone testing. This release does not certify shipment approval or guarantee that unseen/unreadable products have been detected. The count and product review remain part of the check.
