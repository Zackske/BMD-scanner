# BMD Scan 4.0.0

Choose Volle doos or Stapelscan before entering the expected product count. Both routes share the same animated, themed quantity popup, translated into all ten app languages. The count is entered by the operator; it is never inferred from example screenshots.

Volle doos keeps the original marker workflow: instructions, overview photograph, four overlapping detail photographs, registration confirmation and checklist.

Stapelscan opens the live camera immediately after quantity entry, without a tutorial, markers or a four-photo requirement. A saved scan uses one real captured image. Distinct identical codes remain separate products. Retaking replaces the current capture instead of adding duplicate rows; prior originals remain in the local session folder. Export includes the current referenced image.

Existing format controls, lot colours, product grouping, manual review and count checks remain. No automatic shipment approval is introduced. Older box sessions remain readable.

Validation is performed by the release workflow: JVM tests, lint, native Android emulator camera and wizard tests, APK build and signature verification. A physical phone and a real 200-product carton are not covered by emulator validation; field testing remains necessary.
