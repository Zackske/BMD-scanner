# BMD Scan 4.13.1

The customer search bar stays below the menu header while the customer tiles scroll behind it. The gap below search matches the spacing between the tiles. Continuous scrolling, search and returning to the same position are preserved.

The private customer register stays separate from the public source code and APK. Import the privately supplied customer file on your device. Install this update over the previous BMD Scan to preserve local settings and imported records.

This APK is intended for practical testing on Android. Automated checks cover menus, themes, translations, customer search and scrolling, camera controls, code detection and existing product-check workflows. Physical workplace testing remains necessary.
