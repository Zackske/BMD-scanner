# Reference-style visual assets

The Home artwork was generated with the built-in image generator using Jack's supplied four-theme visual reference as a style reference. These are decorative UI graphics, not camera/scanning test evidence. Production images are transparent WebP files at 512x512; conversion preserves alpha. The original brand logos remain unchanged.

Assets: chrome QR + cyan orbit, chrome customers + green orbit, chrome instruction book + violet orbit, chrome gear + amber orbit, plus red, graphite/cyan, pearl-white/cyan, green/lime and dark-violet header scanners. Green/Purple Home accent recolouring applies only to the bundled decorative assets, never to camera frames or lot identities.

Prompt brief: faithfully extract/reconstruct the corresponding glossy rounded 3D chrome object from the supplied reference; match proportions, frontal or three-quarter product perspective, white specular highlights and dark-blue metallic edge shading; keep the coloured elliptical orbit and restrained sparks; one centred complete object, tight balanced bounds, 8% safe margin; true transparent background; no UI tile/container, no phone/screen, no labels or floor/cast shadow. For scanners: compact handheld barcode scanner, handle angled down-left, head and short light cone facing right; themed materials and tiny gold magic sparks. The book retains its small 1/2/3/check/tool marks as decorative icon details.

Typography: unmodified Nunito and Nunito Italic variable fonts from https://github.com/google/fonts/tree/main/ofl/nunito . Weight 850 is used for native Home labels and the app subtitle; weight 950 italic for BMD. Text remains dynamically localized and separately rendered. SIL Open Font License is bundled at app/src/main/assets/fonts/OFL-Nunito.txt.
